# Dalgıç

Telefonda ve tarayıcıda oynanan bir dalış oyunu. Dal, hazine topla, havan bitmeden tekneye dön, kazandığınla ekipmanını büyüt.

- Oyunun tamamı tek dosyada: `dalgic.html`
- Kontroller: telefonda parmağını basılı tutup yüzmek istediğin yöne sürükle; bilgisayarda ok tuşları / WASD ya da fareyle basılı tut.
- Bölgeler: Sığlık (0–30 m), Mercan Bahçesi, Alacakaranlık, Gece Bölgesi, Abis (1000 m'ye kadar).
- Yükseltmeler: hava tüpü, palet, file çanta, fener, dalış elbisesi.
- Hedef: 1000 metredeki batığın yanında yatan **Derinlerin Kalbi**'ni tekneye getirmek.
